## 4. Technical Audit Findings & Verification Summary

### 4.1 Remediated During ZAFFE-017
1. **Broken JSON Array Form Fields (`InvitationForm::custom_styles` & `InvitationTemplateForm::default_styles`):** Empirical check proved `Textarea` double-encoded associative arrays into JSON strings on save, which breaks array indexing (`$customStyles['primary_color']`). Replaced with Filament `KeyValue` components and verified array round-trips + public invitation rendering in `AdminFeatureCoverageTest`.
2. **`UserForm` & `UserPolicy` Hardening:** Made `password` optional on Edit (`dehydrated` only when filled) with `minLength(8)`, constrained `role` to `Select` (`user` / `admin`), enforced `unique(ignoreRecord: true)` on `email`, added `role` filter and `invitations_count` column to `UsersTable`, and guarded `UserPolicy::delete` against self-deletion or deleting the last remaining admin.
3. **Missing Policies on 4 Models:** Added `TemplateCategoryPolicy`, `PlatformSettingPolicy`, `RsvpResponsePolicy` (view + export + spam delete only; `create`/`update` disabled), and `SubscriptionPlanPolicy` (all `false` for Release 1 deferral).
4. **Disconnected `PlatformSetting` System (`OPEN_QUESTIONS #9`):** Added `value` column and `group` filter to `PlatformSettingsTable`, cache invalidation and `whatsappUrl()` on `PlatformSetting`, and wired live settings into `components/layouts/marketing.blade.php`, `layouts/marketing.blade.php`, `components/layouts/base.blade.php`, `layouts/base.blade.php`, and `pages/contact.blade.php`.
5. **Category Deactivation Gap:** Added `InvitationTemplate::scopeAvailableForSelection()` so deactivating a `TemplateCategory` in Filament hides its templates across `/templates`, previews, creation, and `InvitationEditor::changeTemplate()`.
6. **Media Orphan Prevention:** Added `Invitation::booted()` `deleting` hook so Filament single and bulk deletes purge local `cover_photo` and `InvitationPhoto` assets from `Storage::disk('public')`.
7. **Operational Monitoring & Formula-Safe Admin CSV Export:** Created `OperationsMonitor` (`/admin/operations-monitor`), added failed-job count to `PlatformStatsOverview`, replaced `RsvpResponseResource` Create/Edit pages with `ViewRsvpResponse` (`RsvpResponseInfolist`) and formula-safe CSV export via shared `App\Support\CsvSanitizer::cell()`.

### 4.2 Open Items Flagged for Product Owner Decision / Post-Release 1
- **Unmerged `F15` Branch (`origin/feature/ZAFFE-015-short-urls-and-og-tags`):** Decide whether to merge `F15` into `dev` for Release 1 or defer.
- **Safe User Suspension (`users.is_active`):** Adding user suspension requires a schema migration and PO rules defining whether a suspended user's published invitations should remain live or be hidden.
- **Static FAQ / About CMS & Persistent Contact Form:** `/contact` currently uses a client-side Alpine success state; `/faq` and `/about` are static Blade views. Adding DB-backed CMS tables or mailing inquiries requires PO scope approval.
- **KSA Optional `bride_name` & Demo Unsplash Assets:** Align code validation (`DashboardController::store`, `InvitationEditor`, `InvitationForm`) with `SAUDI_MARKET_DECISIONS.md` regarding optional `bride_name`, and replace demo Unsplash image URLs in `pages/home.blade.php` and `DatabaseSeeder.php`.
- **Duplicate `'resend'` Array Key in `config/mail.php`:** Documented in `docs/DEPLOYMENT_CHECKLIST.md`; clean up in configuration hygiene pass.
